# Legacy app icon: question mark + plane

The app icon used up to October 2026 (3D question mark with a cartoon plane), kept for reference.

- `iOS/AppIcon.appiconset` — iPhone, iPad, App Store marketing and Mac sizes
- `tvOS/App Icon & Top Shelf Image.brandassets` — Apple TV layered icon and Top Shelf images
- `watchOS/AppIcon.appiconset` — Apple Watch

To restore one, copy the folder back into the matching `Assets.xcassets` (replacing the current set).
These folders sit outside the Xcode project's synchronized folders, so nothing here is bundled into the app.
