A backup data source: if Flightradar24 stops answering, the radar switches to adsb.lol's open ADS-B data on its own and says "Backup data · adsb.lol" along the bottom, then switches back when Flightradar24 returns. Open data has no routes, so flights show without their airports until then. Settings → Radar → Data source can also pin one source.
Try: set Data source to Open data and check the radar keeps working, with the tag along the bottom.
